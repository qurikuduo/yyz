# 使用说明 · USAGE

> 本文档随里程碑更新。当前进度：M0–M6 全部完成，应用可交付使用。

## 1. 启动

### Docker（推荐）
```bash
docker compose up --build
```
打开浏览器访问 http://localhost:8080 。数据保存在宿主机 `./data/`。

### 本地开发
```bash
npm run install:all
npm run dev:server   # 后端 :8080
npm run dev:web      # 前端 :5173（/api 已代理到后端）
```

## 2. 使用流程

1. **选择方案**：在首页选择单量表（PHQ-2 / PHQ-9 / SDS / CES-D / BDI-II / DSM-5）或"综合评估"。
2. **录入个人信息**：年龄、性别、病程与治疗史、教育/职业（用于更科学的解读与个性化建议；量表切点固定不受影响）。
3. **逐题作答**：MBTI 式一题一屏或分组作答，可回退修改，带进度条。
4. **查看结果**：总分、严重度带、可视化；**逐题解释**（该题测量的症状域、DSM 映射）+ **用户答案解析**（所选选项含义、得分贡献、简短解读）+ 评判依据。
5. **设置密码并生成分享 URL**：测评保存后生成唯一 URL（形如 `/r/<token>`），需用户设置的密码才能查看。
6. **知识库**：分类浏览循证自助资料与权威来源。可下载工作表（Markdown，随镜像打包）：抑郁自助导引、行为激活日程表、CBT 思维记录表、情绪与睡眠日记、危机资源卡；外部权威链接指向 WHO / NIMH / NHS / MSD / Mayo Clinic / findahelpline。

## 3. 查看已保存结果

访问 `http://localhost:8080/r/<token>`，输入设置时使用的密码即可查看。

## 4. 语言切换

右上角可在中文 / English 间切换，偏好会被记住。

## 5. 安全提示

- 本工具**非诊断**。结果仅供参考，鼓励寻求专业评估。
- 若自杀意念相关题目为阳性，结果页会**强制显示危机资源**，无论总分高低。
